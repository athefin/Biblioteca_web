PASOS PARA QUE LES FUNCIONE EN SUS COMPUTADORAS
Como agregué un modelo nuevo (Libro) y cambié la estructura de Reseña, deben hacer esto al descargar mis cambios:
1. Abran la terminal y ejecuten: 
   .\.venv\Scripts\python.exe manage.py makemigrations
   .\.venv\Scripts\python.exe manage.py migrate

   *OJO:* Como cambiamos el campo "libro" de Reseña de texto a número, es probable que Django les pregunte qué hacer. Elijan la opción 1 (Provide a one-off default now) y escriban un número (ej: 1). Si les da error de base de datos, simplemente borren la tabla de reseñas en Supabase o en el admin y vuelvan a correr el migrate.

2. Para llenar la base de datos con libros de prueba, vayan a la URL:
   http://127.0.0.1:8001/poblar/

3. Si quieren probar el nuevo diseño del catálogo, vayan a:
   http://127.0.0.1:8001/libros/
